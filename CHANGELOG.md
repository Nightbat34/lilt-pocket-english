# Changelog

## V1.0 — 2026-11-24

V1.0 public release, refreshed in place on 2026-11-24.

- Includes the existing 400 × 500 quiet, English-first vocabulary app and all 100 cards in the 40 / 35 / 25 topic mix.
- Uses a transparent Suzuha Amane cutout for the executable, window and system tray icons; removes the white exterior background.
- Makes learning text selectable and copyable, with Ctrl+C and a context menu.
- Adds visible parts of speech, corresponding meanings and examples, and word-form notes.
- Adds recursive in-app double-click lookup with Back navigation, common inflection handling and an offline dictionary.
- Adds Windows file version 1.0.0.0, source build instructions and portable release downloads.
- Preserves the 100-card topic mix, review scheduling, settings and existing progress format.
