# Changelog

## V1.0 — 2026-11-24

First public release of Lilt Pocket English.

- Includes the existing 400 × 500 quiet, English-first vocabulary app and all 100 cards in the 40 / 35 / 25 topic mix.
- Uses the supplied Suzuha Amane image for the executable, window and system tray icons.
- Adds Windows file version 1.0.0.0, source build instructions and portable release downloads.
- Keeps the learning flow, vocabulary, settings and progress format unchanged from the initial local build.
